# UniFi Access Intercom Resident List Workaround

This is an editable template for UniFi Access Intercom displays.

The current UniFi Access Intercom interface does not show the resident list directly on the main screen. Visitors first have to press the resident list button before they can select a tenant and ring.

This template provides a visual instruction background that points visitors to the resident list button.

## Files

- `unifi-access-intercom-resident-list-template.ai`  
  Editable Adobe Illustrator source file.

- `unifi-access-intercom-resident-list-bg.png`  
  Exported background image for the intercom display.

## Purpose

Many visitors expect the tenant or resident list to be visible immediately. This background is a practical workaround until the native UniFi Access interface provides a better resident-list-first layout.
